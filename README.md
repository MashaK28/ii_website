# Душевные вопросы

Одностраничный генератор случайных вопросов для лёгкого, глубокого и нового общения.

**Открыть сайт:** [https://mashak28.github.io/ii_website/](https://mashak28.github.io/ii_website/)

## Как запустить на компьютере

Сайту не нужны установка программ, сборка или дополнительные библиотеки.

### Вариант 1: открыть файл

1. Скачайте проект или сохраните файл `index.html` на компьютер.
2. Откройте `index.html` двойным щелчком — сайт запустится в браузере.

### Вариант 2: запустить локальный веб-сервер

Этот вариант удобен для проверки сайта локально. Нужен установленный Python 3.

1. Скачайте проект и откройте терминал (в Windows — PowerShell) в папке проекта.
2. Выполните команду:

   ```bash
   python3 -m http.server 8000
   ```

   В Windows, если команда выше не сработала, используйте:

   ```powershell
   py -m http.server 8000
   ```

3. Откройте в браузере <http://localhost:8000>.
4. Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`.

## Как пользоваться

1. Выберите категорию: **Все**, **Лёгкие**, **Глубокие** или **Для знакомства**.
2. Нажмите **Следующий вопрос**.
3. Счётчик показывает, сколько вопросов было задано в текущем сеансе, а карточка — номер текущего вопроса.
4. Вопрос не повторяется два раза подряд, даже при смене категории.

В каждой из трёх тематических категорий есть восемь вопросов. Сайт адаптируется к экрану телефона и учитывает системную настройку уменьшения анимации.

## Публикация и обновление сайта

Сайт размещается на GitHub Pages. После отправки изменений в ветку `main` GitHub Actions автоматически опубликует обновлённую версию. Статус публикации можно посмотреть во вкладке **Actions** репозитория. Первая публикация может занять несколько минут.

## Файлы проекта

- `index.html` — сайт, стили, вопросы и интерактивная логика.
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.
